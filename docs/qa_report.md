## 1. Відтворення з нуля (A1)

Команди (з кореня клону):

1. `python3.13 -m venv .venv`: успішно.
2. `.venv/bin/pip install -r requirements.txt`: успішно.
3. `.venv/bin/python -m src.run_all`: **помилка на кроці 1/16 `check_env`**.

```
File "src/check_env.py", line 46, in main
    url = TERRACLIMATE_OPENDAP.format(var=CHECK_VAR)
KeyError: 'year'
ПОМИЛКА на кроці check_env (код 1), зупиняюсь.
```

Причина: шаблон `TERRACLIMATE_OPENDAP` у `src/config.py` має два підстановлювані поля `{var}` і `{year}`, а `check_env.py` передає лише `var`. T16 прогнав ланцюжок лише з `--skip check_env`, тому помилку не побачив. README описує запуск без `--skip`, отже заявлена команда з README у чистому клоні не працює.

Далі запущено `run_all --skip check_env` (завантажено з мережі в порожній `data/raw/`):

- `download` (TerraClimate PDSI, ppt, soil, tmax, pet): 997,5 с, успішно.
- `boundaries`, `rivers` (Overpass): успішно (boundaries 179 с), повторів не знадобилось.
- `season`, `drought_years`, `causes`, три рисунки: успішно.
- `download_yields` (stat.gov.ua): **помилка** `zb_rosl_10.pdf: відповідь не є PDF`. Під час перевірки сервер Держстату віддавав `HTTP 307` на `/maintenance` для всіх адрес, включно з головною (за годину до цього `curl -I` повертав 200 для тих самих URL). Це збій на стороні сервера, а не коду; код правильно видалив не-PDF і зупинився.
- Обхід: 11 PDF Держстату скопійовано з робочої папки в клон (не з мережі), запущено решту кроків (`yield_tables`, `yields`, `build_slides`, `build_methodology`, `build_prompts_pdf`): код 0, 74,9 с. ## 6. Знахідки (за пріоритетом)

1. **Критична.** `src/check_env.py:46` викликає `TERRACLIMATE_OPENDAP.format(var=CHECK_VAR)` без `year`. Перша команда з README падає в чистому клоні. Виправлення, яке я не вносив: `.format(var=CHECK_VAR, year=LAST_COMPLETE_YEAR)` (імпорт уже є) і така сама зміна для запасного варіанта, якщо він використовує той самий шаблон; або прибрати `check_env` з `run_all`. Після правки повторити команду в чистому клоні. Окремо: T16 мав би прогнати без `--skip`.
2. **Висока.** Повне завантаження Держстату цього разу не перевірено через `/maintenance` на stat.gov.ua. Потрібен повторний запуск `src.download_yields` (11 PDF, ≈38 МБ) після відновлення сайту. Код поводиться правильно, але в README варто сказати, що збій сервера дає помилку `відповідь не є PDF`.
3. **Середня.** `producer.com` (403) і `agris.fao.org` (405) не відкрились автоматично; відкрийте їх у браузері. Обидва посилання лише в `docs/sanity_sources.md`.
4. **Низька, правило точності.** `docs/methodology.md` і `methodology.pdf` пишуть «близько 30 % ... близько 70 %» (розд. 5) і «близько 70 %» (розд. 8, лісосмуги), тоді як точні 29,52 % і 70,48 % уже є на слайдах. Для узгодження замініть на 29,52 % і 70,48 %. У README: «TerraClimate близько 48 МБ, Держстат близько 38 МБ» нечислові оцінки обсягу, правило до них не застосовується.
5. **Низька.** Прогін `run_all` без мережі в `README` описаний («повторний запуск іде з кешу»), але `check_env` потребує мережі, що README також зазначає; після виправлення знахідки 1 суперечності не буде.
6. **Низька.** Слайд 4 посилається на нотатки доповідача, а в PDF слайдів нотаток немає. Фермер із PDF джерел не побачить; вони лише в pptx і методології.
7. **Спостереження.** Чекліст вимагає окремого кроку перевірки даних: його варто додати як короткий скрипт або розділ у методології (пропуски, діапазони, одиниці).
