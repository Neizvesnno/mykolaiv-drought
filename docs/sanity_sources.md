## Що з цього випливає для T06

- Надійно підтверджені для Миколаївщини: 2007 (офіційний документ), 2020 (новини, помірна впевненість), 2024, 2025 (новини). 2012 підтверджено для півдня загалом.
- Гіпотеза Supervisor'а про 2007, 2020, 2024 підтвердилась; 2012 і 2025 варто додати до списку для перевірки.
- Для 1958-1990 прямих джерел по області не знайдено (є лише загальноукраїнські 1963, 1968 з однієї анотації).
- Новини не дають кількісного порівняння з нормою; використовувати їх як якісну перевірку "рік у списку чи ні", а не як еталон величини.
