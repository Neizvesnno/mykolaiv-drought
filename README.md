# Посуха в Миколаївській області, 1958-2025

Тестове завдання для Лабораторії моделювання річкових систем УкрГМІ. Проєкт показує на картах і графіках, які роки були посушливими в Миколаївській області, як часто це траплялося раніше й тепер, і що це означало для урожаю пшениці. Аудиторія презентації: фермери, тому слайди написано простою мовою.

## Головні висновки

Числа взято з `data/processed/summary.json`, `causes.json` і `yields.csv`. Посуха тут означає сезон квітень-вересень, у якому індекс Палмера (PDSI) не вищий за −2, а опадів або вологи ґрунту щонайменше на 20 % менше за норму 1991-2020.

- За 68 років (1958-2025) підтверджено 17 посушливих сезонів, тобто 1 рік із 4,00.
- У 1958-1990 таких сезонів 4 із 33 (12,12 %, 1 рік із 8,25), у 1991-2025 уже 13 із 35 (37,14 %, 1 рік із 2,69).
- Причини: сезон став спекотнішим на 1,92 °C, опадів стало менше на 11,36 %, потенційне випаровування зросло на 80,40 мм. Це 70,48 % загального погіршення водного балансу (114,08 мм). Збіг у часі не доводить причину.
- Пшениця (Держстат): у 2012 році зібрали 17,3 ц/га проти 29,8 ц/га в сусідні звичайні роки (−41,88 %), у 2020 році 27,0 проти 38,6 ц/га (−29,96 %). Середня втрата за 7 посушливих років, для яких є база порівняння, становить −16,51 %.

Правило точності: у файлах даних числа без округлення, відсотки й індекс PDSI показано з 2 знаками лише там, де їх читає людина.

## Як відтворити

Три команди з кореня репозиторію:

```
python3.13 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m src.run_all
```

`src/run_all.py` по черзі запускає весь ланцюжок (check_env, download, boundaries, rivers, season, drought_years, causes, три рисунки, download_yields, yield_tables, yields, build_slides, build_methodology, build_prompts_pdf), друкує, що робить кожен крок, і зупиняється на першій помилці. Лише перелік кроків: `.venv/bin/python -m src.run_all --list`; пропустити крок: `--skip check_env`.

Передумови:

- Python 3.13.
- LibreOffice (команда `soffice` у PATH): з нього збираються PDF.
- Інтернет для першого запуску, приблизно 90 МБ: TerraClimate близько 48 МБ, збірники Держстату близько 38 МБ, OpenStreetMap близько 5 МБ. Наявні файли в `data/raw/` кроки завантаження пропускають, тож повторний запуск іде з кешу. Крок `check_env` читає лише метадані з сервера TerraClimate і потребує мережі.

## Структура

- `src/`: код, один скрипт на крок; параметри методу в `src/config.py`.
- `data/`: `raw/` (завантажене, не в git), `boundaries/` (межі й ріки), `processed/` (результати).
- `figures/`: рисунки для слайдів.
- `slides/`: презентація (`.pptx` і `.pdf`).
- `docs/`: методологія, тексти слайдів, нотатки про причини й урожайність.
- `orchestration/`: завдання, звіти й журнал роботи AI-агентів.

## Роль AI

Задачі виконували AI-агенти за інструкціями Павла через папку `orchestration/` (Supervisor і воркери, JSON-схеми, журнал). Ключові рішення приймав Павло: поріг −20 %, сезон квітень-вересень, категорії років, правило точності чисел і формат слайдів; повний журнал у [prompts.pdf](prompts.pdf).
